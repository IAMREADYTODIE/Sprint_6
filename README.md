# Финальный проект 6 спринта. Тестирование сервиса "Яндекс.Самокат"

## 📝 Описание
Проект представляет собой набор UI-автотестов для веб-сервиса "Яндекс.Самокат".
Реализован паттерн **Page Object Model**.
В тестах используются явные ожидания и параметризация.
Браузер для тестов: **Firefox**.

## 🛠️ Стек технологий
- Python
- Selenium WebDriver
- Pytest
- Allure

## 📂 Структура проекта
- `tests/` — пакет с тестами (разделены по функционалу: главная страница и заказ)
- `pages/` — классы Page Objects (методы взаимодействия с элементами)
- `locators/` — файлы с локаторами
- `data.py` — тестовые данные и URL
- `conftest.py` — фикстуры (настройка драйвера Firefox)

## 🚀 Запуск тестов

**1. Установка зависимостей:**

    pip install -r requirements.txt

**2. Запуск всех тестов:**

    pytest

**3. Запуск с генерацией отчета Allure:**

    pytest --alluredir=allure_results
    allure serve allure_results
